# Ferrum 1.8.9 (`Ferrum-rust`)

**Ferrum 1.8.9**는 JVM이나 OpenGL 래퍼를 거치지 않고 **100% 네이티브 Rust + Vulkan(`wgpu` 24)** 으로 구현한 실험용 Minecraft 1.8.9 호환 클라이언트 및 싱글플레이·LAN 런타임입니다.

> **안내**: 본 저장소에는 마인크래프트 원본 게임 파일(`.jar`), 텍스처, 사운드 등 저작권이 있는 에셋이 포함되어 있지 않습니다. 실행하려면 PC에 정품 Minecraft 1.8.9가 설치되어 있어야 하며, 최초 실행 시 로컬 설치본에서 리소스를 추출해 사용합니다.

---

## 주요 기능

### 1. 네이티브 Vulkan 렌더링 & 최적화
- **고속 지형 파이프라인**: 내부 은면 제거, Greedy Meshing, Frustum / Back-face 컬링, 프레임 예산 기반 비동기 청크 메싱 및 GPU 버퍼 업로드
- **최대 128청크 원거리 지형(LOD)**: 근거리 정밀 블록 메시 너머로 최대 128청크까지 단계별 표면 LOD 타일을 비동기로 생성·표시하고 공유 버퍼 아레나로 드로우콜을 병합
- **가시성 및 조명 처리**: 스카이라이트·블록 조명 분리 전파, 반블록·계단 주변 부드러운 조명(AO) 보정, 반투명 블록 거리 정렬, 벽 너머 개체 오클루전(엔티티 컬링)
- **확장 비디오 설정 UI**: Sodium 스타일 비디오 설정 화면에서 그래픽 품질, 시야 거리, 부드러운 조명, 구름, 입자, VSync, 엔티티 컬링, 청크 업로드 예산 등을 실시간으로 조절

### 2. 월드 생성 및 차원 시스템
- **원본 1.8.9 시드 호환 생성**: 오버월드(`DEFAULT`, 평지, 대형 바이옴, 증폭, 사용자 지정)의 바이옴·지형·동굴·협곡·광맥·마을·폐광·던전·식생을 원본 난수 순서에 맞춰 생성
- **네더 & 엔드 차원 지원**: 네더 포털 생성·좌표 스케일링·포털 링킹, 네더 요새 생성, 엔드 차원 이동 및 **엔더 드래곤 보스전·엔드 크리스탈·출구 포털** 구현
- **기존 월드 호환 및 백그라운드 저장**: 기존 1.8.9 Anvil(`.mca` / `level.dat`) 월드 읽기 지원 및 플레이 중 프레임 끊김 없는 비동기 스냅샷 자동 저장(`saves/native-v4`)

### 3. 싱글플레이 시뮬레이션 & 게임플레이
- **전용 20Hz 로컬 틱 워커**: 렌더링 프레임레이트와 분리된 전용 스레드에서 물리·블록 틱·레드스톤·몹 AI를 처리하여 높은 FPS 유지
- **서바이벌 & 블록 상호작용**: 채굴 속도·도구 등급·내구도, 허기·포만도, 포션 및 상태 효과(우유 해독 포함), 인챈트 광택(Glint), 유체(물·용암) 흐름, 낙하 블록(모래·자갈·모루·드래곤 알), 스폰지 흡수 및 네더 건조, 레드스톤 회로 및 명령 블록
- **개체 및 탈것**: 32종 몹 렌더링·AI·전투·번식, 주민 거래, 말(점프 게이지·인벤토리)·돼지·광산 수레(일반/동력/감지/활성화 레일)·보트 탑승 및 운행
- **3D 공간 오디오**: 거리 감쇠 및 스테레오 패닝이 적용된 3D 월드 사운드·배경 음악(`rodio` OGG 디코딩)

### 4. 전용 런처, LAN 공유 및 멀티플레이 (Protocol 47)
- **네이티브 Win32 런처 (`launcher`)**: Microsoft 기기 코드(Device Code) OAuth 정품 계정 로그인 및 오프라인 닉네임 전환 지원
- **LAN 월드 열기**: 싱글플레이 도중 **Esc → Open to LAN**으로 같은 네트워크의 다른 클라이언트와 즉시 월드 공유
- **1.8.9 멀티플레이 접속**: 프로토콜 버전 47 기반 외부 서버 상태 조회, 직접 연결, 탭 자동완성 채팅, 서버 리소스팩 다운로드 지원

## 시작하기

### 요구 사항
- **운영체제**: Windows 10 / 11 (64-bit)
- **그래픽**: Vulkan 1.2 이상을 지원하는 GPU 및 최신 드라이버
- **개발 도구**:
  - [Rust](https://rustup.rs/) (`stable-x86_64-pc-windows-msvc`)
  - [Python 3.9+](https://www.python.org/) (최초 리소스 추출 스크립트 실행용)
- **원본 클라이언트**: `%APPDATA%\.minecraft` 경로에 공식 런처로 한 번 이상 실행된 **Minecraft 1.8.9** 설치본

### 1. 리소스 준비
로컬에 설치된 Minecraft 1.8.9에서 텍스처·사운드·언어 파일을 `.local/resources`로 가져옵니다.

```bat
decompile.bat
resources.bat
```

### 2. 릴리즈 빌드
클라이언트 본체(`ferrum189.exe`)와 계정 런처(`launcher.exe`)를 빌드합니다.

```powershell
cargo build --release --locked --bins
```

### 3. 실행
배치 스크립트 또는 빌드된 런처로 실행할 수 있습니다.

```bat
:: 기본 실행 (리소스 확인 후 게임 시작)
start.bat

:: 계정 로그인 런처 실행
target\release\launcher.exe
```

자주 쓰는 CLI 실행 인자:

```bat
:: 메뉴 없이 즉시 크리에이티브 월드로 진입
start.bat --play --creative --seed 189

:: 기존 .minecraft 세이브 폴더 열기 (원본 파일은 읽기 전용으로 유지)
start.bat --world "%APPDATA%\.minecraft\saves\New World"

:: 1.8.9 멀티플레이 서버 직접 접속
start.bat --connect 127.0.0.1:25565 --username Player

:: 헤드리스 월드 생성·메싱 무결성 점검
target\release\ferrum189.exe --check --render-distance 4 --fresh
```

## 기본 조작법

게임 내 **설정 → 조작(Controls)** 메뉴에서 33개 키 바인딩을 자유롭게 변경할 수 있습니다.

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 마우스 | 이동 / 시점 회전 |
| `Space` / `Ctrl` / `Shift` | 점프·수영 / 달리기 / 웅크리기(탈것 하차) |
| `Space` 두 번 | 크리에이티브 비행 전환 (`Space` 상승 / `Shift` 하강) |
| 좌클릭 / 우클릭 | 공격·채굴 / 블록 설치·상호작용·아이템 사용 |
| 마우스 휠 / `1`–`9` | 핫바 슬롯 선택 (휠 클릭: 블록 선택) |
| `E` / `Esc` | 인벤토리 열기 / 창 닫기·일시 정지 메뉴 |
| `Q` / `Ctrl + Q` | 아이템 1개 버리기 / 스택 전체 버리기 |
| `T` / `/` | 채팅창 열기 / 명령어 입력 (`Tab` 자동완성) |
| `F1` / `F2` / `F3` | HUD 숨김 / 스크린샷 저장(`screenshots/`) / 디버그 정보 |
| `F5` / `F11` | 시점 전환(1인칭·3인칭 후면·전면) / 전체 화면 전환 |
| `F3 + A` / `F3 + B` / `F3 + H` | 청크 다시 그리기 / 히트박스 표시 / 아이템 상세 툴팁 |

## 프로젝트 구조

```text
Ferrum-rust/
├── src/                    # 클라이언트·렌더러·월드 생성·시뮬레이션·네트워크 핵심 Rust 소스 및 WGSL 셰이더
│   ├── bin/launcher.rs     # Win32 네이티브 계정 관리 및 실행 런처
│   ├── vanilla/            # 1.8.9 지형·구조물·조명·물리·전투·아이템 규칙 구현
│   ├── commands/           # 싱글플레이 슬래시 명령어 처리기
│   └── ui/                 # 메뉴·인벤토리·채팅·Sodium 스타일 비디오 설정 UI
├── sodium-dev/             # 비디오 설정 UI 아이콘 리소스 참조
├── scripts/                # 리소스 추출·원본 비교·성능 측정 보조 스크립트 (Python / PowerShell)
├── tools/java/             # 개발 중 원본 동작 대조에 사용하는 오라클 도구 코드
└── docs/                   # 상세 기술 문서
    ├── compatibility.md    # 기능별 구현 및 호환 범위 정리
    ├── protocol-47.md      # 멀티플레이 프로토콜 47 패킷 지원 현황
    └── benchmark.md        # 렌더링·스트리밍 벤치마크 재현 안내
```

더 자세한 호환성 범위와 네트워크 패킷 명세는 [docs/compatibility.md](docs/compatibility.md), [docs/protocol-47.md](docs/protocol-47.md), [docs/benchmark.md](docs/benchmark.md)에서 확인할 수 있습니다.
